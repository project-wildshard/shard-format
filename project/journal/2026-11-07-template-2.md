# Template 2 lands here, by hand

- J168 and row 16: Template 2 is `corpus/handwritten`, 170 files with no
  build. The sections are JSON a person holds, the blobs frozen Blender
  output (J88). The folder is the pinned `fbd3aba57d` as it stands, and
  `shardfile pack` makes those exact bytes with format alone.
- `pack` is what makes "by hand" true: edit a section in any layout and
  hashes, packs, the source hash and the receipt follow. It needed nothing
  new in `src/format`, because `assembleOutputShardfile` alone gives the
  source hash. So no release is owed by this.
- `validate` takes a tarball now, since that's what a host runs.
- The packed-install test found the `shardfile` bin could never run
  installed: Node won't strip types under `node_modules`. `bin.mjs` installs
  the format hook first. `corpus/handwritten/**` and `src/cli/*.mjs` joined
  `files`.
- J186 shaped the tests. The hash isn't pinned here, so editing Template 2
  stays free. Hostile uploads run through the real CLI and no refusal's
  words are pinned. One seeded walk over real blobs replaces the
  one-case-per-field rows: a hostile author writes true hashes, so the walk
  does too, and 12,000 scratch inputs reached the GLB, KTX2, image and
  collider parsers with no crash. 400 inputs run here, in under 3 s.
- All of it is `src/ci`, never a hook.
