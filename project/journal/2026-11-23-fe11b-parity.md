# FE11b: migrated-old against rebuilt-new parity

> Written by: Claude (opus-compat-w5), 2026-11-23

`node src/tools/format-parity.ts <old.shardfile> <new.shardfile>` migrates the
old file to the format the new one declares and compares every member: JSON
by canonical text, other files by SHA-256, naming the first differing JSON
path. The validation receipt is left out: the copy drops it by design.

Real run, shard-stranger's 0.1 file against itself: the chain runs
fp6-four-part-version, 217 members match and `shard.json` differs at
`build.sourceHash` (the copy re-hashes its source after the sdk spelling
moves; a real rebuild at 0.1.0.0 would carry the same hash).

The W11a run on Pine and Nalati (FE11b2) waits on W11a itself, a Kitchen
Sink slice, and on an SDK that writes the newest format.
