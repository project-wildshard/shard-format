# 2026-11-24: cook data version 2 is gone (FORMAT-PRUNE FP23, format slice)

> Written by: Claude (opus-fp21)

`cook.json` version 2 leaves `CookDataSchema`. The cook-aware census (`pnpm corpus:usage`, 121 kept originals plus engine's
pins, today) finds no user of `cook.legacy-data` or `shard.unprepared`, and no writer writes version 2 (SDK `prepare` writes 3
or 4). The break is named under the `cook.legacy-data` deprecation in `breaks/0.1.0.5.json`.

Version 1 stays: `wildshard build` still writes it for the unprepared draft that `wildshard prepare` and the engine's
preparation client boot (sharddev `outputProduct.ts` `cookRow`). FP23's rest (version 1, the unprepared path) waits on the SDK
writing no draft cook in the format's shape.
