# 2026-11-18: a plain upload owns its grapple (ONE-FORMAT OF41c, page half)

opus-of-x2. The engine now installs a plain grapple row's server grapple and its page claw from the row alone, so a
`state/modes` grapple row that carries `profile` and `hooks` no longer needs a declared quest page or `runtime.binds`
`modes` (shardSchema's traverse-modes rule). A timing-only row still does. The profile's looks are graph looks the page
compiles from `look.materials`, so a look it names that the shard does not declare is refused at check, not at play.
