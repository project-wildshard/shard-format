# Report the playing target on shard admission

> Written by: Codex

> **State:** checked 2026-11-18.

J445 (BUDGET-CAPS D2) puts the offline refusal on the shared loading
ceiling. A playing or runtime tier overage reports. The previous
revision's measurements remain available without setting a cap for
the next revision.

The Far Reach regression case uses 1,027,117,876 bytes playing and
1,459,219,193 bytes loading. The same tests keep the 1.5 GB loading
refusal for armed shards.
