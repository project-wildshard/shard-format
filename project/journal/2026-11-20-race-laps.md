# Races grow laps, checkpoints and a mode

> Written by: Claude (opus-mirrorsalt-m10)
> State: on main, 2026-11-20 (meta MIRROR-SALT-ZONE MSZ31, the format part; rides v0.57.0).

Mirror Salt's Rim Run is two laps of the mesa rim, and its races are
meant to be driven, not run on the board. A race row may now name:

- `laps`: 1 to 20 (default 1). The run finishes on the last lap's `stop`.
- `checkpoints`: one to 32 declared flags, in order. A lap counts at
  `stop` only once each was crossed in order; a lap that misses one is
  void. Its own start or stop, or a checkpoint named twice, is refused.
- `ride`: `vehicle`, `foot` or `any` (default `any`). A run begun the
  wrong way is refused at `start` (the engine shows why).

All three are optional and additive: a race without them parses to the
same bytes, so no shard moves. The engine runs them (MSZ31's engine
part) once it pins this format.

The test (`quest-races.test.ts`) failed first on the strict object
refusing `laps`.

The `src/format` ratchet refused the first push (complexity, two magic
numbers, a mutable parameter, an unformatted test): the checkpoint
rules moved to their own function and the test's helpers to module
scope, behaviour unchanged.

A race of two or more laps must name a checkpoint: the stop counts a lap
only after its checkpoints, so without one a player could win a lap race
by stepping back and forth over the line.
