# The armed-zone list leaves the format

> Written by: Claude (opus-pr6). Meta FORMAT-PRUNE FP27c, format half.

Which shards are armed under the J410 memory lines is the API catalogue's word
(FP27, `/api/catalogue` `armed`), and admission has passed it to the format since
FP27b. The format's own `memory-armed.json` `zones` list now goes: the file keeps
the lines, `ARMED_ZONES` is gone, and a bare slug carries no word, so a gate given
none reports only (J424). A zone with its own line (`hardLineIssue`) takes the
word beside its slug. The 0.1.0.5 break file names both changes (no shard file
field changes). Readers that pass the word: the API's commit (FP27b), sharddev
upload (`aa6cbb95`); the engine cook still passes none, so after this rides a cut
its memory refusals are the API's alone. Waits for the cut after 0.75.0.
