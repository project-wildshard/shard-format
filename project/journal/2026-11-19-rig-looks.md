# Rig looks (ONE-FORMAT OF19d1)

- 2026-11-19, opus-of19b5: a look row may name a scene model library's
  baked rig: recipe `platform.rig`, parameters `{ library, body? }`, no
  material, animation `platform.rig` with no parameters (the rig plays
  its own clips). `rigLookRules` checks the row and that the library is
  a `models` library of `world/scenes`; it runs inside
  `clientOwnershipRules`, so every assembled product gets it.
- A data page whose plan keeper stands no body and whose every declared
  spawn's species has a look no longer needs `species.program` or
  `actors/species-programs`: Sunscar Dunes can drop its last species
  program once the engine draws `platform.rig` (OF19d2).
- Kept out of `rows.ts`: it is at the ratchet's dependency cap, so the
  row half rides the cross-section rule instead of `parseRows`.
