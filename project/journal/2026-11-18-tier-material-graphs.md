# Charge authored GPU work to its tier

Use the product's named tier for material graph admission. Author
programs can narrow their own cap and the tier still caps nested graphs.
The post stack also gets a tiered pass count, inside the existing
full-screen instruction ceiling.

Pinned Nine uses 55 graphs. The largest cost is 3,980 nodes, four
samplers and 5,358 estimated instructions across the catalogue maxima.
The older unnamed runtime tier keeps the same physical graph ceilings.
