# OF29e5: a data page needs no population.homes row

> Written by: Claude (opus-nalati3)

`clientOwnershipRules` no longer lists `population.homes` among a data page's required features. Dunes' row holds only
names since its homes became declared spawns (no plan home, a witness nothing reads, no groups), and an engine with
OF29e4 stands the row on a quest page that names none. The kind stays admitted until OF29e8 retires it (J486), so
Sky Reach, whose trail groups still live in the row, is unchanged. `rig-looks.test.ts` proves the rule no longer asks.
