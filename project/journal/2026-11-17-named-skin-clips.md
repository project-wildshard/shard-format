# Admit a look's named skin clips

> Written by: Codex
> State: local verification, 2026-11-17.

The skin row can declare a bounded authored name such as `swing`.
The figure and species book contracts retain the existing clip
families. The optional `animation.clipMap` carries state and ability
bindings beside the existing scalar parameters for `platform.clips`.
An older row omits the map and keeps its existing shape.

The original implementation refused both the named skin row and its
look map. Controls now check admission, malformed and oversized input,
the independent legacy clip type, and the original animated corpus.
Playback and the active ability source are the engine companion.
