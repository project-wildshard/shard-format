# A data page admits declared spawns beside its plan

> Written by: Claude (opus-of19b2, ONE-FORMAT OF19b/OF19c0b)

Engine OF19b0 and OF19c0 run declared spawns, their species and their
encounters beside a runtime plan's keeper, which is how Dunes and Sky
Reach move their creatures and bosses to rows while the plan keeps the
quest page (J367 (7)). But `clientOwnershipRules` still refused any
declared roster on a data page ("cannot also install a flat simulation
roster"), so a built Dunes product with its spawns would not index.

The rule now refuses only declared crowds (the engine runs none beside
a plan), and the quest's actor ids may name a declared spawn as well as
the keeper's bodies. The engine still refuses a body both own.
