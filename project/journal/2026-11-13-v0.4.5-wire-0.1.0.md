# Release notes: shard-format v0.4.5 and wire 0.1.0 (NPM-PUBLISH NP3)

The first real versions on npm (`@wildshard/shard-format@0.4.5`,
`@wildshard/wire@0.1.0`), published by CI from the tags; the 0.0.1
placeholders came first (NP12). What changed since v0.4.4:

- Packing a shard now measures its memory and cost figures again
  instead of copying old ones, and validate warns when a shard's
  claimed memory is smaller than its files.
- New `@wildshard/shard-format/immutable` export and
  `parseShardfileField`, so engine and the sdk share one copy of them.
- `MoverBox` and `AnimalDims` are exported as types.
- Both packages install from npm by version, not only by git link.
- wire leaves 0.0.0: its first numbered version is 0.1.0, tagged
  `wire-v0.1.0` on the commit that sets it.
