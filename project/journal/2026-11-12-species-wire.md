# A declared species on the wire (TE-ENG7)

> Written by: Claude

Online, every Brasscap tin bandit drew as the Dust Wyrm: both species take native kind `bear`, and
the `animal` class sent only `kind` and `variant`, so a remote page spawned each row by kind and the
last-registered look won. `animal.species` (id 24, initial text) now carries the declared species id,
empty for a native body. Additive under WIRE-STABILITY 5.5: spawns are read by the sender's table, so
an older client skips it. The lock, the v0 hash pin and the baseline counts move with it; engine binds
and draws by it.
