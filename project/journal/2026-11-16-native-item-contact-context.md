# Native item contact references

> Written by: Codex
> State: source built, 2026-11-16. ONE-FORMAT OF31d3b2a.

Item contact targets previously resolved only ordinary species rows. A
product whose actors live in its defining species-program section could
not explicitly name those identities. The SDK therefore preserves the
old native weapon policy until this reference contract reaches consumers.

Keep the same shard shape. The optional section context derives identities
through the existing strict species-program reader, including page/native
and program declarations. It is not an arbitrary id list. The public
schema and parser without context retain their original strict behavior.

Product assembly, folder admission, asset admission and streaming admission
carry that context without skipping their existing checks. The complete
section inventory and exact bytes still cross the normal defining guards.
Two new real-product regressions failed semantic admission before the fix;
known identities now pass, while absent/unknown targets, malformed native
metadata, changed bytes and incomplete inventories still refuse.

Consumer integration remains OF31d3b2b; removal of implicit content follows
only its native combat/save parity in OF31d3b2c. No serialized feature or
new format dialect, content edits, or visual judgement belongs here.
