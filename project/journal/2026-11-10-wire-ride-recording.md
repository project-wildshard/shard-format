# Actual mounted transport capture

The third WS3 scenario uses an available camp horse in the actual Nalati
native product. Initial arena placement is explicit; real ride acts,
commands, mounted law, gait, frame words and events then produce the
four-second stream. All bytes survive the mandatory frozen replay.

The CI-only complete-recording proof checks the mount/dismount events,
115 mounted frames, exact command-loss interval, recovery and all caps.
No timing, live server, renderer or benchmark pass is claimed. The dense
scene and timing harness remain open.
