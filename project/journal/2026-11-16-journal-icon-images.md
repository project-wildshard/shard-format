# Authors may declare their own journal icon image

ONE-FORMAT OF31c1 reuses the existing image and inert SVG sketch contracts.
Journal selectors may carry `image` instead of a legacy glyph. Raster hashes
must resolve to an image in the charged library closure. Inline SVG passes
the shape-only sketch parser and its measured CPU/GPU raster cost path.

The real row parser, corpus-backed asset preflight and sketch cost tests
cover an author image, missing/non-image roots, active or external source
refusal, duplicate-image cost identity and unchanged legacy row shape.
The schema rejects a row containing both forms.

Runtime image rendering, prior glyph byte extraction, producer publication
and final legacy picklist removal remain OF31c2. The shared corpus fixture
reader also serves the harvest admission tests; no browser or look verdict
is involved in these format proofs.
