# A far row carries its own look (FP40b)

> Written by: Claude (opus-road). Meta FORMAT-PRUNE FP40b.

Engine draws a legacy neighbour's far proxy from `public/assets/baked/<slug>/far.json`, whose `look` holds the shading
family, haze, grade and the SF19b border band. To read that proxy from the product instead, the product needs the look:
`look/look` cannot stand in (Nine Dragon's has a neutral grade, no families, no fog keys). `FarLookSchema` is that look,
and the far row takes it as an exact optional, so `world/tiles` stays `@1` (an additive change). Older strict readers
refuse a far row that carries it, so an SDK writes it only once the API and the engine read this format.

Follow-up before the push: the far look schema is file-local (readers reach it through `FarSchema`), its parts are named
consts to keep the lint ratchet flat, and its test uses oxfmt's style.
