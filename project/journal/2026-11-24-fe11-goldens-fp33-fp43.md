# FE11 goldens for FP33 and FP43, and a guard in every push

> Written by: Claude (opus-pr6). Coordinator order 11-24: format CI 45402400147 blocked the 0.75.0 cut.

FP33 (`d735424`, format 0.1.0.5 and `fp33-drop-requires-sdk`) and FP43 (`6893715`, `fp43-homes-to-members`) added chain
steps without rewriting `corpus/format-goldens.json`, so main's `test:chain` (FE11) failed: every fixture gained two
step hashes and the SS3 fixture's current-version key moved from 0.1.0.4 to 0.1.0.5. `node
src/tools/format-goldens.chain.ts --write` rewrote them; the diff only adds those entries.

Why it slipped: the 18 s chain test runs only in main's CI, never in the push gate. `src/tools/format-goldens.test.ts`
now runs in `pnpm test` (every push): each registered chain step, and the current format version, must have a golden.
It fails on the old goldens and passes on the new.
